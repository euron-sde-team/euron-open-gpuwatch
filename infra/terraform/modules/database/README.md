# `database` module

PostgreSQL 16 on RDS: private, encrypted with the CMK, TLS enforced (`rds.force_ssl`), Performance Insights, Enhanced Monitoring, automated backups, deletion protection. Consumers add their own security-group ingress rules.

What it holds: hosts and GPUs, raw metric samples range-partitioned by day (the worker creates upcoming partitions and drops whole days past `RAW_RETENTION_DAYS`, so retention never runs a bulk `DELETE`), 1-minute and 1-hour rollups, workload usage and cost attribution, insights, alert rules and events, notification channels (webhook signing secrets sealed with KMS before they are stored), API keys, users and the append-only audit log. Cost report CSVs live in S3. No extensions are required.

Parameter group: `rds.force_ssl = 1`, `log_min_duration_statement = 1000` (ms) and `idle_in_transaction_session_timeout = 60000` (ms), so a crashed task cannot hold locks that block rollups or the daily partition upkeep.

The API reads a single `DATABASE_URL`, so the master password is generated by Terraform (`random_password`, URL-safe characters) and exposed only as the sensitive `connection_url` output, which the `secrets` module stores in Secrets Manager. It is therefore in the Terraform state: keep state in an encrypted, access-controlled backend (see `envs/*/backend.tf.example`). Rotate with `terraform apply -replace=module.database.random_password.master` followed by a new ECS deployment.

Not applied in `local-floci`: locally Postgres is the `postgres:16` Compose container.

## Inputs

| Name | Description | Type | Default |
|---|---|---|---|
| `name_prefix` | Prefix for every resource name. | `string` | required |
| `vpc_id` | VPC id. | `string` | required |
| `subnet_ids` | Private subnets for the DB subnet group (2+ AZs). | `list(string)` | required |
| `kms_key_arn` | CMK for storage and Performance Insights. | `string` | required |
| `database_name` | Initial database name. | `string` | `"gpuwatch"` |
| `master_username` | Master user name. | `string` | `"gpuwatch_admin"` |
| `engine_version` | PostgreSQL major (or major.minor) version. | `string` | `"16"` |
| `instance_class` | Instance class. Graviton (t4g/m7g/r7g) recommended. | `string` | `"db.t4g.medium"` |
| `allocated_storage` | Initial gp3 storage in GiB. | `number` | `50` |
| `max_allocated_storage` | Storage autoscaling ceiling in GiB. | `number` | `500` |
| `multi_az` | Synchronous standby in a second AZ. | `bool` | `false` |
| `backup_retention_days` | Automated backup retention. | `number` | `7` |
| `deletion_protection` | Block accidental deletion. | `bool` | `true` |
| `monitoring_interval` | Enhanced Monitoring granularity in seconds (0 disables). | `number` | `60` |
| `skip_final_snapshot` | Skip the final snapshot on destroy (throwaway envs only). | `bool` | `false` |

## Outputs

| Name | Description |
|---|---|
| `address` | DB hostname. |
| `port` | DB port. |
| `database_name` | Database name. |
| `instance_identifier` | RDS instance identifier (CloudWatch dimension). |
| `security_group_id` | DB security group; consumers add ingress rules against it. |
| `master_username` | Master username. |
| `connection_url` | Sensitive. `postgresql+asyncpg://...?ssl=require`, for the `secrets` module. |
